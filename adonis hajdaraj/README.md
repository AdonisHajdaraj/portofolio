# Portfolio React App

Kjo është një portofol React + Bootstrap për Adonis Hajdaraj.

## Si të nisni

1. Instaloni paketat:
   ```bash
   npm install
   ```
2. Nisni aplikacionin në zhvillim:
   ```bash
   npm run dev
   ```
3. Hapni URL-në që shfaqet në terminal.

## Si të ndërtoni

```bash
npm run build
```

Kjo krijon dosjen `dist` për publikim.
